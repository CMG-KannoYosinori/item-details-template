## 全体の流れ（チェックリスト）

プロジェクト ID が `15403` の場合の例です。自分の案件の番号に読み替えてください。

### A. ファイルを用意する

1. [ ] GitHub で **Code → Download ZIP**
2. [ ] ZIP を解凍する
3. [ ] **`00000html` フォルダだけ残す**（ほかは全部削除してよい）
4. [ ] `00000html` を作業用の場所へ移す
5. [ ] VS Code / Cursor で **`00000html` フォルダを開く**（中のファイル単体ではなく、フォルダごと）

残す中身:

```
00000html/
├── はじめてガイド.md   ← 今読んでいるファイル
├── README.md           ← くわしい説明
├── dist/               ← ここを主に編集・納品する
├── src/                ← 見た目（色・余白など）の編集元
└── .vscode/            ← 自動設定（触らなくてよい）
```

### B. 番号を案件用に変える（最初に必ず）

1. [ ] サイドバーで `00000html` フォルダをクリックして選ぶ
2. [ ] 検索置換を開く（Mac: `Cmd + Shift + F` / Windows: `Ctrl + Shift + F`）
3. [ ] 次を **すべて置換** する

```
00000  →  15403
```

4. [ ] フォルダ名を手動で変える: `00000html` → `15403html`
5. [ ] HTML ファイル名を手動で変える: `dist/00000.html` → `dist/15403.html`

> 置換のあと、変えたくない番号（商品 URL など）が変わっていないか、ざっと確認する。

### C. プレビューできるようにする

1. [ ] 画面下のステータスバーで **Watch Sass** をクリック（監視開始）
2. [ ] `dist/15403.html` を開く
3. [ ] 右クリック → **Open with Live Server**（または同様のメニュー）
4. [ ] ブラウザでページが表示されればOK

### D. ページを作る（日常作業）

触る場所はこの2つだけです。

| やりたいこと | 開く場所 |
| ------------ | -------- |
| 文章・画像・ボタンなどの中身 | `dist/〇〇〇〇〇.html` |
| 色・余白・レイアウトなどの見た目 | `src/styles/` の中の `.scss` ファイル |

**やってよいこと**

- HTML に文章や画像を足す・直す
- 案件だけの見た目は `src/styles/pages/_project.scss` に書く
- 既存の部品（ボタンなど）をまねして使う

**やらなくてよい／やってはいけないこと**

- `dist/styles/style.css` を直接いじらない（上書きされて消える）
- `npm` やターミナルは使わない
- わからないファイルは触らない

見た目のファイルを保存すると、Watch Sass が自動で `dist/styles/style.css` を更新します。ブラウザを見れば反映されます。

### E. 公開前

1. [ ] HTML 内の CSS を、ローカル用から本番用（CDN）に切り替える  
   （`./styles/style.css` をコメントアウトし、本番 URL の行を有効にする）
2. [ ] アコーディオン（開閉メニュー）を使っている場合  
   - `dist/scripts/accordion.2.js` をサーバへアップロード  
   - HTML 末尾の script もローカル → 本番 URL に切り替える
3. [ ] 画像を所定の場所へ置く／アップロードする
4. [ ] Live Server と Watch Sass を止めてもよい

## 困ったとき

| 症状 | まず試すこと |
| ---- | ------------ |
| 見た目が変わらない | Watch Sass が動いているか確認。`src` 側を保存したか確認 |
| `src/styles` の隣に変な `.css` が増えた | Watch を止める。フォルダの開き方が違う可能性あり（`00000html` を直接開く） |
| ページが開かない | Live Server で `dist` 内の HTML を開いているか確認 |
| 用語やルールがわからない | [`README.md`](./README.md) を見る |
